# Invert Binary Tree

## Description

Given the `root` of a binary tree, invert the tree, and return its root.

### Example 1

![diagram](figures/226-1.svg)

```text
Input: root = [4,2,7,1,3,6,9]
Output: [4,7,2,9,6,3,1]
```

### Example 2

![diagram](figures/226-2.svg)

```text
Input: root = [2,1,3]
Output: [2,3,1]
```

### Example 3

```text
Input: root = []
Output: []
```

### Constraints

- The number of nodes in the tree is in the range `[0, 100]`.
- `-100 <= Node.val <= 100`
