# Largest Palindrome Product

## Description

Given an integer `n`, return the largest palindromic integer that can be
represented as the product of two `n`-digit integers. Since the answer can be
very large, return it modulo 1337.

### Example 1

```text
Input: n = 2
Output: 987
Explanation: 99 × 91 = 9009, 9009 % 1337 = 987.
```

### Example 2

```text
Input: n = 1
Output: 9
```

### Constraints

- `1 <= n <= 8`
