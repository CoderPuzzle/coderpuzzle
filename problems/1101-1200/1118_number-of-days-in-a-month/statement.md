# Number of Days in a Month

## Description

Given a year `year` and a month `month`, return the number of days of that
month.

### Example 1

```text
Input: year = 1992, month = 7
Output: 31
```

### Example 2

```text
Input: year = 2000, month = 2
Output: 29
```

### Example 3

```text
Input: year = 1900, month = 2
Output: 28
```

### Constraints

- `1583 <= year <= 2100`
- `1 <= month <= 12`

## Hints

### Hint 1

Does February have 28 days or 29 days?

### Hint 2

Think of Leap years.
