# Unique Binary Search Trees

## Description

Given an integer `n`, return the number of structurally unique BST's (binary
search trees) which has exactly `n` nodes of unique values from `1` to `n`.

### Example 1

![diagram](figures/96-1.svg)

```text
Input: n = 3
Output: 5
```

### Example 2

```text
Input: n = 1
Output: 1
```

### Constraints

- `1 <= n <= 19`
