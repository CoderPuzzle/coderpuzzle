# Valid Palindrome II

## Description

Given a string `s`, return `true` if `s` can be a palindrome after deleting at
most one character from it.

### Example 1

```text
Input: s = "aba"
Output: true
```

### Example 2

```text
Input: s = "abca"
Output: true
Explanation: You could delete the character 'c'.
```

### Example 3

```text
Input: s = "abc"
Output: false
```

### Constraints

- `1 <= s.length <= 10⁵`
- `s` consists of lowercase English letters.
