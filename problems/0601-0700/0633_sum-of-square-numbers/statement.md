# Sum of Square Numbers

## Description

Given a non-negative integer `c`, decide whether there're two integers `a` and
`b` such that `a² + b² = c`.

### Example 1

```text
Input: c = 5
Output: true
Explanation: 1 * 1 + 2 * 2 = 5
```

### Example 2

```text
Input: c = 3
Output: false
```

### Constraints

- `0 <= c <= 2³¹ - 1`
