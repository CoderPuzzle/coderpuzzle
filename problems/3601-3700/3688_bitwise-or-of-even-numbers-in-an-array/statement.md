# Bitwise OR of Even Numbers in an Array

## Description

Given an integer array `nums`, return the bitwise OR of all the even numbers
in it.

If there are no even numbers in `nums`, return `0`.

### Example 1

```text
Input: nums = [1,2,3,4,5,6]
Output: 6
Explanation: The even numbers are 2, 4, and 6, and 2 | 4 | 6 = 6.
```

### Example 2

```text
Input: nums = [7,9,11]
Output: 0
Explanation: There are no even numbers, so the result is 0.
```

### Example 3

```text
Input: nums = [1,8,16]
Output: 24
Explanation: The even numbers are 8 and 16, and 8 | 16 = 24.
```

### Constraints

- `1 <= nums.length <= 100`
- `1 <= nums[i] <= 100`
