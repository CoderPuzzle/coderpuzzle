# Solutions — Word Ladder II

## BFS Distances plus DFS Enumeration

Treat the words as an implicit graph whose edges join words differing by exactly one letter. A single BFS from `beginWord` computes the shortest distance of every reachable word and, in the same pass, records a DAG of shortest-path edges: an edge `word -> nxt` is kept only when `nxt` is first discovered from `word` (so its distance is one greater) or already sits exactly one level below `word`. Edges between same-level words or pointing backward can never lie on a shortest ladder, so discarding them prunes the reconstruction to exactly the paths that matter.

![BFS levels of the one-letter graph: hit (0), hot (1), dot and lot (2), dog and log (3), cog (4).](figures/solution-bfs-levels.svg)

Neighbors are generated by substituting each of the 25 other letters at each position and looking the candidate up in a hash set — cheap here because words are at most 5 letters and the dictionary holds at most 500 entries. `beginWord` is discarded from the set so the search can never route back through it, and if `endWord` is absent from the dictionary the function returns an empty list immediately.

Reconstruction is a plain DFS from `beginWord` that follows only the recorded edges; since every edge advances exactly one BFS level, every root-to-`endWord` walk in this DAG is automatically a shortest ladder. The DFS appends a copy of the current path each time it reaches `endWord`, reusing one buffer via append/pop. With N dictionary words of length L, K shortest ladders in the output, and D the ladder length, the BFS generates at most 26 · N · L^2 candidate strings and the DFS costs the size of its output.

**Complexity:** `O(26 · N · L^2 + K · D)` time, `O(N · L + K · D)` space.
